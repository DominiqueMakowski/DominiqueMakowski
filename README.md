## Main projects

- [x] I am the cofounder of the [**easystats**](https://github.com/easystats/) collection of R packages
- [x] Creator of [**NeuroKit2**](https://github.com/neuropsychology/NeuroKit), the most popular Python toolbox for neurophysiological signal processing
- [x] My [**teaching materials**](https://github.com/DominiqueMakowski/teaching) are open source


## Data analysis

- [x] [**cogmod**](https://github.com/DominiqueMakowski/cogmod): An R package that implements cognitive computational models
- [x] [**SequentialSamplingModels.jl**](https://github.com/itsdfish/SequentialSamplingModels.jl): Contributor to a Julia package for RT models

## Neuropsychology

- [x] [**Pyllusion**](https://github.com/RealityBending/Pyllusion): 🤯 A Python module for generating visual illusions
- [x] [**PyShaman**](https://github.com/RealityBending/PyShaman): 🧙‍♂️ A Python software for inducing altered states of consciousness
- [x] [**Neuropsydia**](https://github.com/neuropsychology/Neuropsydia.py): A Python Module for Creating Experiments, Tasks and Questionnaires.
- [x] [**CognitiveControl**](https://github.com/neuropsychology/CognitiveControl): A neuropsychological task measuring different aspects of cognitive control (processing speed, inhibition, conflict resolution...)
- [x] [**RestingState**](https://github.com/neuropsychology/RestingState): Standard resting state protocol with brief mental state assessment
- [x] [**PatientAssessmentApp**](https://github.com/neuropsychology/PatientAssessmentApp): Easy Neuropsychological Assessment of Patients Scores and Deficits

## Utilities

- [x] [**OpenMuse**](https://github.com/DominiqueMakowski/OpenMuse): The first Open Python Muse S Athena EEG Decoder

- [x] [**TruScanEEGpy**](https://github.com/neuropsychology/TruScanEEGpy): Utility functions to work with Deymed's TruScan EEG system
